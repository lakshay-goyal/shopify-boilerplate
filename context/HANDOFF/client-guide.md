# Client guide — change anything yourself, no code needed

Every item below is editable in Shopify admin or the theme editor
(Online Store → Themes → Customize).

- Texts, headings, buttons: theme-editor settings per section/block.
- Colors, fonts, spacing: Theme settings.
- Images and collections: pickers in each section (no fixed handles).
- Menus, pages, policies: Content / Menus in admin (`../ABOUT/` is the source).
- Products, prices, stock: Products in admin — the theme adapts automatically.

If something looks unchangeable, that is a bug per our customizability
guarantee — report it and it will be fixed.
