# EXCALIDRAW/ — visual understanding without code

Source `.excalidraw` scenes (JSON, editable in Excalidraw), by concern:

- `user-flows/` — shopper journeys (onboarding, purchase, personalization).
- `workflows/` — business/system workflows (order processing, fulfillment).
- `architecture/` — high-level system view (non-technical for clients).

Created by `diagram-generator`. Export PNG/SVG alongside only when the
client needs it. Every diagram links back to its RFC/SPEC/decision.
