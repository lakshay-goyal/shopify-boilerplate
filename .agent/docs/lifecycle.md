# Lifecycle

```
Research → RFC(proposed) → HUMAN accepts → SPEC → ecommerce-check →
TDD (before code) → worktree → implement → verify loop → review →
theme audit → merge → test-review → INSIGHT → progress → next
```

Traceability: every feature owns a Context ID (`FEAT-001`) referenced by
its RFC, SPECs, TDDs, worktree/branch, decisions, diagrams, and insight.
`workflows/feature.md` is the executable version of this page.
